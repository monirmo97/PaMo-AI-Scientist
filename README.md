# PaMo — AI Scientist Research Assistant

A structured research atlas for understanding AI Scientist systems, AI research agents, autonomous scientific discovery, and research automation.

## Goals

- Build a complete learning path for AI Scientist research.
- Analyze important systems and papers from 2020–2026.
- Separate verified evidence from claims.
- Build a connected knowledge map of the field.

## Structure

- `course/` — learning materials
- `systems/` — individual system analysis
- `daily/` — short research updates
- `weekly/` — LinkedIn drafts
- `references/` — papers, organizations, repositories
- `concepts/` — core ideas and relationships
